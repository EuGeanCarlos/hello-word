# Hello World

Primeiro exercício de página web com mensagem de boas-vindas e script JavaScript.

## Tecnologias

- HTML
- JavaScript

## Funcionalidades e utilização

Abra a página e observe a mensagem de boas-vindas e o comportamento do script original.

## Como executar

```bash
git clone https://github.com/EuGeanCarlos/hello-word.git
cd hello-word
python -m http.server 8000 --directory "hello_world"
```

Requer Python 3 para o servidor local. Abra http://localhost:8000.
